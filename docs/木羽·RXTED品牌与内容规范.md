# 一、品牌概述

## 1.1 品牌定位

木羽（RXTED）是一个以个人成长、技术探索、独立思考和创造实践为核心的个人品牌。

它不只是一个技术博客，而是一个长期记录个人经历、知识积累、技术实践与生活感悟的数字空间。

从软件开发到硬件设计，从技术探索到生活记录，持续学习、持续创造，并通过文字和作品留下成长的轨迹。

**品牌核心：木有根，羽有翼。**

## 1.2 品牌含义

「木羽」由两个意象组成：

**木 · ROOT**

- 扎根：保持独立思考，建立自己的知识体系。
- 生长：持续学习，在实践中积累经验。
- 创造：将想法转化为真实的作品。
- 坚韧：面对变化，保持长期主义。

**羽 · WING**

- 自由：不被单一领域和固有边界限制。
- 探索：保持好奇心，勇于尝试未知。
- 远方：不断拓展认知与能力的边界。
- 独立：拥有自己的方向和判断。

木代表根基，羽代表方向。

木让我们拥有扎根的力量，羽让我们拥有飞向远方的勇气。

## 1.3 品牌精神

**木有根，羽有翼。**

既要脚踏实地，也要仰望星空。

既要沉淀积累，也要自由探索。

不急于定义边界，不停止学习与创造。

## 1.4 品牌关键词

- 成长 Growth
- 探索 Explore
- 独立 Independent
- 思考 Thoughts
- 创造 Create

# 四、品牌视觉设计

## 4.1 整体视觉方向

建议采用：

**自然主义 + 现代极简 + 东方意境**

整体视觉不追求复杂装饰，而是强调自然、安静、克制和留白。

视觉关键词：

- 自然：森林、树木、山峦、天空。
- 生长：枝叶、年轮、根系、嫩芽。
- 自由：羽毛、飞鸟、风、远方。
- 极简：干净布局、清晰层次、适度留白。
- 东方：含蓄、沉静、自然意境。

## 4.2 Logo 设计方向

建议设计两种 Logo 形式。

**A. 图形 Logo**

核心概念：树枝与羽翼结合。

设计思路：

- 以一段向上生长的树枝作为主体。
- 树枝末端逐渐转化为羽毛形态。
- 通过线条表达木与羽的融合。
- 整体保持简洁，避免过度写实。
- 既能体现自然生长，也能表达自由探索。

**B. 文字 Logo**

推荐排版：

木羽  
RXTED

或者：

木羽 · RXTED

中文「木羽」作为主要识别名称，RXTED 作为英文品牌标识。

## 4.3 Logo 使用场景

| 使用场景       | 推荐形式                 |
| -------------- | ------------------------ |
| 网站首页       | 图形 Logo + 木羽 + RXTED |
| 网站导航栏     | 简化图形 + 木羽          |
| 浏览器 Favicon | 单独图形符号             |
| 个人名片       | 图形 Logo + 品牌名称     |
| 社交头像       | 图形 Logo                |
| 页脚           | 木羽 · RXTED             |

# 五、品牌色彩规范

整体采用低饱和度自然色系，以森林墨绿和暖米白作为核心颜色。

## 5.1 主色

| 颜色名称 | HEX       | 用途                     |
| -------- | --------- | ------------------------ |
| 森林墨绿 | `#20372E` | 品牌主色、Logo、深色背景 |
| 苔藓绿   | `#788C78` | 辅助色、交互状态         |
| 暖米白   | `#F2EFE6` | 页面背景、卡片背景       |
| 暖棕色   | `#A58B70` | 点缀、装饰、辅助元素     |
| 墨黑色   | `#252923` | 正文、标题               |

## 5.2 推荐色彩比例

- 暖米白：60%
- 森林墨绿：25%
- 苔藓绿：8%
- 暖棕色：4%
- 墨黑色：3%

## 5.3 网站配色建议

**浅色模式**

- 页面背景：`#F2EFE6`
- 内容背景：`#FAF9F5`
- 标题文字：`#252923`
- 正文文字：`#555C54`
- 主按钮：`#20372E`
- 辅助强调：`#788C78`

**深色模式**

- 页面背景：`#171F1B`
- 内容背景：`#202B24`
- 标题文字：`#EAE9DF`
- 正文文字：`#B9C0B5`
- 主按钮：`#788C78`
- 辅助强调：`#A58B70`

深色模式应保持低对比度的自然氛围，避免使用过亮、过于鲜艳的颜色。

# 六、字体规范

建议使用中英文混合字体体系。

| 使用场景     | 推荐字体       |
| ------------ | -------------- |
| 中文品牌标题 | 思源宋体       |
| 中文正文     | 思源黑体       |
| 英文标题     | Space Grotesk  |
| 英文正文     | Inter          |
| 代码展示     | JetBrains Mono |

设计原则：

- 品牌标题可以使用宋体，突出东方气质。
- 正文使用无衬线字体，保证阅读体验。
- 英文标语使用适度字间距。
- 代码区域使用等宽字体。
- 避免同时使用过多字体。

# 七、图片与摄影风格

整体采用低饱和度、自然光线、具有空间感的摄影风格。

## 7.1 自然与成长

推荐主题：

- 森林与树木
- 松枝与嫩芽
- 树木年轮
- 山间雾气
- 阳光穿过树叶

表达品牌中的「木」：扎根、生长、积累。

## 7.2 思考与记录

推荐主题：

- 安静的书桌
- 笔记本与书籍
- 窗边光影
- 清晨与黄昏
- 山间远景

表达沉淀、思考与长期记录。

## 7.3 技术与创造

推荐主题：

- 代码编辑器
- 电路板与电子元件
- 工作台
- 机械结构
- 创作过程

表达探索、实践与创造。

## 7.4 生活与探索

推荐主题：

- 山川与湖泊
- 远方的道路
- 飞鸟与天空
- 城市与自然
- 旅行中的风景

表达自由、探索与远方。

## 7.5 图片处理原则

- 优先自然光摄影。
- 采用低饱和度色彩。
- 避免强烈滤镜。
- 尽量保持画面简洁。
- 图片应具有故事感，而不是单纯装饰。

# 八、博客内容体系

建议将博客内容划分为五个主要栏目。

| 栏目 | 英文名称 | 内容方向                       |
| ---- | -------- | ------------------------------ |
| 生长 | Growth   | 学习记录、个人成长、经验积累   |
| 探索 | Explore  | 新技术、新领域、实验与尝试     |
| 创造 | Create   | 软件开发、硬件设计、项目作品   |
| 思考 | Thoughts | 技术观点、个人思考、知识总结   |
| 生活 | Life     | 日常记录、旅行、兴趣与生活感悟 |

栏目不需要严格限制内容边界，可以根据实际文章逐步调整。

建议保持内容的长期连续性，而不是为了分类而分类。

# 九、网站设计应用

## 9.1 首页

首页重点展示品牌与近期内容。

建议结构：

1. 顶部导航：Logo、首页、归档、分类、关于。
2. 品牌 Hero：木羽 · RXTED、座右铭、个人介绍。
3. 文章列表：最新文章、精选文章。
4. 分类入口：生长、探索、创造、思考、生活。
5. 个人介绍：技术方向、兴趣、项目。
6. 页脚：品牌标语、社交链接、版权信息。

首页视觉应简洁，重点突出文章内容。

## 9.2 文章详情页

建议使用舒适的阅读布局：

- 清晰的标题和文章元信息。
- Markdown 内容区域。
- 自动生成目录。
- 当前阅读进度。
- 代码块与引用样式。
- 评论区域。
- 上一篇与下一篇文章。

阅读体验优先于装饰效果。

## 9.3 归档页面

采用时间轴形式组织文章。

支持：

- 年份归档。
- 分类筛选。
- 标签筛选。
- 关键词搜索。

## 9.4 关于页面

建议包含：

- 木羽品牌介绍。
- 个人简介。
- 技术方向与兴趣。
- 项目与开源经历。
- 联系方式。
- 品牌座右铭。
